# bethelmelesse.github.io

Personal portfolio site for **Bethel Melesse Tessema** — AI/ML Engineer & Researcher
specializing in NLP, Computer Vision, and Computational Drug Discovery.

🔗 **Live:** <https://bethelmelesse.github.io/>

## Built with

Static HTML, CSS, and vanilla JavaScript — no build step or dependencies.

```text
index.html          # page content
asset/css/style.css # styles + design tokens
asset/js/main.js    # nav, scroll progress, scroll-reveal
asset/img/          # images
asset/pdf/          # resume
```

## Local preview

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deployment

Hosted on GitHub Pages from the `main` branch. Pushing to `main` publishes automatically.
